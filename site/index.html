導入

Installed in a minute

Kufu isn't in the Chrome Web Store yet, so you add it by hand. The window below shows what you'll see at each step.

    kufuapp.pages.dev
    Does it work in Edge, Brave or Opera?

    It should work in browsers built on Chromium. Open edge://extensions, brave://extensions or opera://extensions and follow the same steps.

    Why does it need Developer mode?

    That's how Chrome installs anything from outside the Web Store. Chrome may remind you about it now and then. Kufu's code is open on GitHub, so you can read it.

    How do I update?

    Download the new zip, replace the files in the same folder, and press the reload arrow on Kufu's card in chrome://extensions. Your settings stay.

    Can I use my own Unsplash photos?

    Yes. Get a free Access Key at unsplash.com/oauth/applications, then paste it with a collection link in Settings, Background.

    Can I move the folder afterwards?

    Chrome keeps reading from that folder, so keep it where it is. If you move it, load it again from the new place.
